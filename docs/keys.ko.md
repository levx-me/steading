# 키와 마우스

[English](keys.md) · **한국어** · [← README](../README.ko.md)

## 열기, 닫기, 옮기기

herdr가 알아보는 에이전트(Claude Code, Codex, OpenCode 등)가 시작되면 그 옆에 deck이 저절로 열립니다.
그 밖의 경우를 위해 herdr의 `config.toml`에 키를 추가하세요.

```toml
[[keys.command]]
key = "prefix+d"
type = "plugin_action"
command = "steading.toggle"
```

- `prefix+d`는 포커스된 패널 옆에 deck을 열거나 닫습니다. deck 위에서 누르면 그 deck을 닫습니다.
- deck은 에이전트 오른쪽에 열립니다. deck에서 `L`을 누르면 위로(다시 누르면 오른쪽으로) 옮겨지고,
  그 에이전트의 deck은 계속 그쪽에 열립니다.
- 닫은 deck은 닫힌 채로 있습니다. 실행 기록은 계속 쌓이고, 다시 열면 보입니다.
- 에이전트가 시작될 때도 열리지 않게 하려면 설정(`,`)에서 **Open with agents**를 끄세요.

## 키

deck에 포커스를 두세요(클릭하거나 herdr의 패널 이동 키 사용). 맨 아래 줄에 지금 쓸 수 있는 키가 항상
표시됩니다.

| 위치 | 키 | 동작 |
|---|---|---|
| 어디서나 | `[` `]`(로그 밖에서는 `tab` `shift+tab`도), `1`–`7` | 이전/다음 탭, 해당 탭으로 이동 |
| | `A` `J` `S` `B` `T` `I` `D` | 밑줄 친 글자로 탭 이동(git은 `I`. `G`는 vim의 맨 아래로 남겨 둠. 로그 안에서는 `B`가 커서 이동이라 제외) |
| | `L` | deck을 에이전트의 반대쪽으로 옮기기 |
| | `,` | 설정: 새 실행을 따라 탭 이동, 에이전트와 함께 덱 열기, jobs 기준 시간(5·10·30초) |
| | `ctrl+c` 또는 탭 줄 왼쪽 `✕` 클릭 | deck 닫기(`q`는 로그에서 목록으로 돌아갈 때만 써서, 잘못 눌러도 닫히지 않음) |
| 실행 목록 | `j` `k`(또는 `↓` `↑`), `gg` `G` | 실행 고르기(최신이 위), 가장 최신으로, 가장 오래된 것으로 |
| | `enter` `l` | 출력으로 들어가기 |
| 출력 | `h` `j` `k` `l`, `w` `b` `e`, `W` `B` `E`, `0` `^` `$`, `{` `}` | 커서 이동(herdr 복사 모드 키). 상자보다 긴 줄은 커서가 올라가 있는 동안 아래 줄로 펼쳐져 전체가 보임 |
| | `gg` `G`, `ctrl+d` `ctrl+u` | 맨 위/맨 아래(`G`는 실행 중인 출력을 다시 따라감), 반 페이지 |
| | `v` `V`, `y` | 글자/줄 단위 선택, 복사(선택이 없으면 커서 줄) |
| | `/` `?`, `n` `N` | 앞/뒤로 검색, 반복 |
| | `tab` `shift+tab` | 커서를 실행 명령 부분과 로그 사이로 옮기기 |
| | 가장자리에서 `h` `j` `k` `l` | 명령 부분과 로그를 하나의 글처럼 넘나들기. 첫 줄에서 `k`, 첫 글자에서 `h`를 누르면 목록으로 |
| | `esc` | 선택 취소, 또는 실행 목록으로 돌아가기 |
| servers | `o` | 브라우저에서 서버 열기 |
| agents | `enter` 후 `j` `k`, `enter`, `esc` | 에이전트 상세에서 버튼과 할 일 사이를 이동하고 누르기 |
| | 할 일에서 `enter` 후 `j` `k`, `ctrl+d` `ctrl+u`, `esc`나 backspace | 그 할 일의 이야기: 만들어진 시각과 그때의 요청, 시작·완료 때 Claude가 한 말, Claude가 언급한 곳. `esc`, backspace, `← task` 클릭으로 돌아가기 |
| | "▾ N more"에서 `enter` 후 `j` `k`, `ctrl+d` `ctrl+u`, `ctrl+f` `ctrl+b`, `ctrl+e` `ctrl+y`, `g` `G`, `esc` | activity 카드가 펼쳐지고 카드 안에서만 자체 커서로 스크롤(vim 키, 오래 걸린 명령에서 `enter`는 jobs의 출력으로). `esc`로 접기 |

방향키는 어디서나 `h` `j` `k` `l`과 같습니다. 실행 목록과 그 아래 실행 상자는 커서가 들어가 있는 쪽 테두리가
탭 색으로 바뀝니다. 커서가 목록에 있으면 실행의 명령과 로그도 흐리게 보입니다(에이전트 상세는 제외).

## 마우스

- 탭, 실행 목록의 항목, 로그 줄, 서버를 클릭합니다.
- 휠은 로그를 스크롤하고, 실행 목록 위에서는 실행을 차례로 고릅니다.
- 로그를 드래그하면 herdr처럼 선택한 부분이 복사되고, 선택 영역 위에 알림이 뜹니다.

복사는 `pbcopy`, `wl-copy`, `xclip` 순으로 쓰고, 없으면 터미널 클립보드(OSC 52)를 씁니다.
